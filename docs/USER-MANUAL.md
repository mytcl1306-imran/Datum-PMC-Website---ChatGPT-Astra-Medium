# User manual

## Public website

Explore service descriptions, published projects and resources. Project search supports title/summary text, category and location. The search page finds published page, service and article text. No results indicates that no matching records have been published.

The three resource tools use your own inputs. Cost is area × supplied rate plus contingency; duration is quantity divided by total daily crew output; consultancy return is net assumed savings divided by fee. They do not fetch market rates or predict real project performance.

Submit the contact form with your name, email, required service, message and consent. A successful submission displays a database reference. Keep confidential documents out of this public form. Newsletter interest is stored as pending; no campaign messages are sent by this build.

## Client workspace

Open `/portal`, enter your provisioned credentials and complete authenticator verification. On first use, set up a time-based authenticator using the displayed secret. Treat the secret as a credential. If it is lost, contact the operator through an independently verified channel; recovery is not automated.

Select a project to view reported progress, milestones, issued invoices, project records and private documents. **Download** creates an expiring link. Select **Open secure download** promptly; request a new link if it expires.

Create an RFI to raise a technical question, or a snag to record an issue. Describe the location, drawing reference and expected action where applicable. Status updates are managed by the project administrator. The portal is not an emergency-reporting channel.

Sign out on shared devices. Sessions expire after 30 minutes of inactivity or eight hours from sign-in. If no projects appear, ask the operator to verify your client membership.
