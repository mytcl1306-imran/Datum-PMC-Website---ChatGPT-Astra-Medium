# DATUM · Engineering consultancy platform

**Delivery status: implemented foundation, not a complete or production-verified fulfilment of the master prompt.**

This package preserves PHP 8.3, MySQL 8 and Supabase Authentication/Storage. It contains application source, SQL migrations, a responsive public site, server-enforced access controls, a CMS and a project portal. It is not a hosted website. External integrations, runtime verification and several requested product features remain incomplete. Read FEATURE-MATRIX.md before planning a launch.

DATUM is a proposed brand, not a claim about an existing registered business. Seeded service descriptions are editable editorial copy. There are no invented client logos, projects, testimonials, credentials, awards or performance statistics. The database starts without operational or portfolio records. Legal and evidence-dependent pages start as drafts.

No PHP dependencies are required beyond the listed extensions; the small autoloader is included. No paid icon package or third-party font is bundled. The requested animation/UI library collection has not been integrated. The CSS, browser JavaScript, logo and architectural illustration are local source assets.

## Important boundaries

The implementation has not been executed with PHP, MySQL, Docker or live Supabase in the creation environment. Only the checks documented in TESTING.md have been run. No security certification, WCAG conformance, SEO score, browser compatibility certification or concurrency guarantee is claimed. The deploy configuration is a starting configuration for a single instance, not an enterprise infrastructure deployment.
