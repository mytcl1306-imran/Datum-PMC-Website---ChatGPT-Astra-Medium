# DATUM brand and component system

DATUM is a proposed identity built around a reference point: precise information that lets a project move forward. Its use is subject to the owner's name and trademark review.

## Visual tokens

| Token | Light value | Purpose |
|---|---|---|
| Ink | #183D35 | Headings, primary actions |
| Paper | #F8F7F2 | Main canvas |
| Surface | #FFFEFA | Cards/forms |
| Muted | #626D64 | Supporting text |
| Accent | #966541 | Labels, details, interaction |
| Line | #D9DDD2 | Borders and separators |
| Tint | #EEF0E7 | Alternate sections |

Dark theme values are defined in `public/assets/site.css`. The site detects the system preference and remembers an explicit choice in localStorage. Contrast has not been formally audited.

Typography uses a local system sans-serif stack to avoid font downloads. Headlines use a light weight, tight tracking and generous line breaks; metadata uses small uppercase labels. The layout uses a 1320 px maximum content width, 90% viewport gutters, 96 px desktop section spacing and 60 px on mobile. Borders are restrained; card radii are 3 px.

The monogram combines a D-shaped structural outline with datum cross-lines. The hero illustration is a vector axonometric building study, not a representation of a completed client project. Editable SVG source is included.

Photography direction for future real assets: natural light, honest site conditions, architectural scale and documented construction details. Secure rights and publication consent. Never present stock or generated construction images as evidence of delivered projects.

Components include a responsive navigation, primary/secondary/text actions, service cards, project cards, process timeline, forms, tables, CMS editor, status messaging and a secure workspace shell. Motion is limited to subtle hover transitions and is disabled for reduced-motion preferences. No ornamental 3D or particle library is loaded.
